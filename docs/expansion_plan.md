# 확장 계획(초안) — 반려인 통합 앱 (2026-11-25)

> 메인: 약·음식·식물 안전 조회와 병용 점검. 부가: 동반 장소, 유치원·호텔, 산책 공원, 산책 기록·공유.

## 1. 기능별 데이터와 난이도

| 기능 | 데이터(무료) | 확인 상태 | 난이도 |
|---|---|---|---|
| 동반 카페·음식점·숙소·관광지 | [한국관광공사 반려동물 동반여행 서비스 OpenAPI](https://www.data.go.kr/data/15135102/openapi.do). 동반 조건·유의사항 포함, 위치 기반 조회 가능 | 존재 확인. 인증키 필요, 개발계정 하루 1,000건 | 낮음 |
| 강아지 유치원·호텔 | LOCALDATA **동물위탁관리업** (동물병원과 같은 사이트, 같은 방식) | 파일 목록에서 확인(`/file/animal_boarding`) | 낮음 — 병원 적재 코드를 재사용 |
| 미용실(부가) | LOCALDATA 동물미용업 | 확인 | 낮음 |
| 산책 공원 | 전국 도시공원 표준데이터 | **미확인** | 낮음~중간 |
| 반려견 놀이터 | 공공데이터셋을 찾지 못함 | 없음 | 직접 수집 필요 |
| **산책 기록 (러닝앱처럼)** | 사용자 GPS | — | **높음** |
| **경로 공유·자랑 (피드)** | 사용자 생성 데이터 | — | **높음** |

공모전 측면: 동물위탁관리업·미용업·동물병원은 **농식품부 소관 인허가 데이터**라서, 농식품 공공데이터 활용 비중이 커진다.

## 2. 산책 기록·공유가 어려운 이유 (먼저 정할 것)
1. **앱 형태**
   - 웹(PWA)은 화면이 켜져 있을 때만 GPS를 기록할 수 있다.
   - 주머니에 넣고 걷는 동안 계속 기록하려면 네이티브 앱(React Native/Expo 등)이 필요하다.
2. **계정·서버 저장**
   - 로그인, 경로 저장, 사진, 좋아요·댓글, 신고·차단이 필요하다.
   - 무료 선택지는 Supabase 무료 티어(쓰기 전에 확인받기)다.
3. **개인정보**
   - 산책 경로는 집 위치를 드러낸다. 출발·도착 주변을 자동으로 가리는 **프라이버시 구역**(러닝앱 방식)이 필수다.
4. **법**
   - 개인 위치정보를 수집해 서비스하려면 「위치정보법」에 따른 위치기반서비스사업 신고가 필요할 수 있다.
   - 출시 전에 확인할 것(미확인).
5. **지도**
   - 카카오맵 JS API: 무료 한도 안에서 쓸 수 있고 키가 필요하다.
   - Leaflet + OpenStreetMap: 키는 없지만 타일 사용 정책을 지켜야 한다.

## 3. 추천 순서
1. **(지금) 안전 조회 마무리 + 공모전 준비물(Phase 5).** 접수(예년 4~6월) 전에 메인 기능이 완성돼 있어야 한다.
2. **장소 탭**: 지도 하나에 동물병원·유치원/호텔·미용실·동반 장소·공원을 보여준다. 공공데이터만 쓰고 읽기 전용이라 1~2주면 된다.
3. **산책 기록(나만 보기)**: 경로 저장, 거리·시간 통계.
4. **공유·피드**: 계정, 프라이버시 구역, 신고 기능까지 갖춘 뒤.
5. **(나중) 애견용품 광고·사고팔기**: 아래 4장.

## 4. 애견용품 광고·거래 (나중 단계, 2026-11-25 추가)
수익 모델이 될 수 있지만, 출시 전에 확인할 것이 많다. 아래는 **법률 확인 전 메모**다.

- **광고와 안전 정보 분리 (서비스 신뢰의 핵심)**
  - 위험·병용 결과 화면에는 광고를 넣지 않는다.
  - 광고비를 받은 제품이 판정에 영향을 주지 않는다는 원칙을 명시한다.
- **팔면 안 되거나 제한이 있을 수 있는 품목** — 플랫폼에서 걸러야 한다.
  - 동물용 의약품: 농식품부·검역본부 안내에 따르면 동물약국·동물병원 등 지정된 곳에서만 팔 수 있고, **온라인 판매·알선은 불법**이다 → 장터에서 동물약 거래 금지 ([농식품부 「동물용의약품 올바르게」](https://www.mafra.go.kr/bbs/home/796/568343/artclView.do)). 사람 약도 개인 간 거래 금지.
  - 사료: 사료관리법 표시 기준
  - **살아 있는 동물**: 동물보호법상 동물판매업 등록이 필요할 수 있다. 개인 분양 글도 제한될 수 있다.
- **거래 형태**
  - 입점 판매(쇼핑몰): 통신판매중개업 신고, PG 결제 연동. 결제 수수료는 유료라 확인받기.
  - 개인 간 중고거래: 사기·분쟁 대응, 신고 기능
- **연결 아이디어**: 안전 조회와 붙이면 차별점이 된다. 예: 고양이 보호자에게 "백합 없는 꽃다발", 앵무새 보호자에게 "PTFE 없는 조리도구" 추천. 이 경우에도 추천 근거는 규칙 DB의 출처를 따른다.

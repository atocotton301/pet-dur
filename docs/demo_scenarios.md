# 시연 시나리오 (실제 응답으로 확인함: 2026-11-25)

> 시연 전: `python scripts/load_db.py` → `python -m uvicorn app.main:app --port 8000` → 휴대폰 크기 브라우저로 http://localhost:8000
> 모든 결과 카드에는 "수의사 감수 전" 표시와 출처 링크가 붙는다. 발표에서는 출처 펼치기를 한 번 보여줄 것.

## 1. "고양이가 타이레놀을 먹었어요" — 국내 제품명 → 성분 → 종별 판정 → 응급 연결
1. 🐱 고양이 선택 → `타이레놀` 검색
2. 사람 약 제품 7개가 뜬다. 예: **타이레놀정500밀리그람 → 🔴 위험**
   - 성분: 아세트아미노펜 🔴
   - 이유: 고양이는 글루쿠론산 포합 능력이 낮아 독성 대사산물이 쌓이고, 메트헤모글로빈혈증·하인츠소체 빈혈·간 손상을 일으킨다
   - 출처: Merck Veterinary Manual, Toxicoses From Human Analgesics
3. **타이레놀콜드-에스정**도 보여준다. 성분 4개 중 아세트아미노펜·슈도에페드린은 🔴, 나머지 2개는 ⚪ 정보 없음 → 종합 🔴. "가장 위험한 성분 기준"이라는 안내가 붙는다.
4. 위험 결과라서 "이미 먹었다면 바로 연락" 안내와 `📍 가까운 동물병원 찾기` 버튼이 나온다. 누르면 가까운 순 목록, 전화 버튼, 24시(추정) 배지가 보인다.
- **강조점**: 해외 앱은 "타이레놀콜드-에스정" 같은 국내 제품명을 모른다. 식약처 품목정보로 성분까지 풀어서 판정한다.

## 2. "강아지에게 포도 줘도 돼?" — 음식
1. 🐶 개 선택 → `포도` 검색(`샤인머스캣`, `건포도`로도 찾아진다)
2. **포도·건포도 → 🔴 위험**
   - 일부 개에서 급성 신부전을 일으키고, 개체 차이가 커서 적은 양도 위험할 수 있다
   - 증상: 구토, 설사, 무기력, 물을 많이 마심 …
   - 출처: Merck Veterinary Manual, Food Hazards
3. 같은 `포도`를 🦜 앵무새류로 바꿔서 검색 → **⚪ 확인된 정보 없음 · 수의사 상담 권장**
- **강조점**: 근거가 없으면 '안전'이라고 하지 않는다. 종별로 결과가 다르다.

## 3. "앵무새한테 아보카도 줘도 돼?" — 특수동물
1. 🦜 앵무새류 선택 → `아보카도` 검색
2. **아보카도 → 🔴 위험**
   - 페르신(persin)이 주 독성 성분으로 추정되며 폐·간 울혈, 부종 등을 일으킨다
   - 출처 2개: Avian toxicoses 리뷰 논문(Front Vet Sci 2025), Pet Poison Helpline
3. 덧붙여 `테플론` 검색 → 코팅 프라이팬 과열 연기 🔴. 앵무새 보호자가 잘 모르는 생활 위험이다.
- **강조점**: 국내에 한국어 정보가 특히 부족한 특수동물을 다룬다.

## 4. (핵심 기능) "강아지가 관절약(카프로펜) 먹는 중인데 애드빌 같이 줘도 돼?" — 병용 점검
1. 🐶 개 → `카프로펜` 검색 → `+ 같이 먹여도 되는지 확인`
   - 카프로펜 카드는 ⚪ 정보 없음으로 나온다. 개에게 처방되는 동물약이라 단독 독성 규칙이 없기 때문이다. 발표 전에 "이 약을 단독으로 먹였을 때의 정보가 아니라, 병용을 확인하려고 담는 것"이라고 말해 둘 것.
2. `애드빌` 검색 → **애드빌정(이부프로펜)** → `+ 같이 먹여도 되는지 확인`
3. 아래 트레이에서 `같이 써도 되는지 확인`
4. **🔴 함께 쓰면 안 돼요**
   - 이부프로펜 + 카프로펜이 **NSAID계 + NSAID계 규칙**에 걸린다(약물군 소속 테이블을 거쳐 연결)
   - 이유: 위장관 궤양·출혈, 간·신장 부작용 위험이 겹친다
   - 출처: 미국 FDA 동물의약품센터
- **강조점**: 사람 약 제품명 → 성분 → 약물군 → 종별 병용 규칙. 보호자가 "집에 있는 진통제를 조금 더" 주는 실제 사고 상황이다.

### 백업 시나리오
- 고양이 + 백합 → 🔴 (신부전). 개 + 백합은 🟢 "일반적으로 독성 보고가 없습니다"로 종별 차이를 보여준다.
- 토끼 + 개·고양이용 벼룩약 성분(피프로닐) → 🔴. 다른 종 약을 쓰면 위험하다는 예시.

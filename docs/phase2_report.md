## 2. 만든 파일

| 파일 | 내용 |
|---|---|
| `data/seed_parts/*.json` | 출처 원문을 읽고 뽑은 규칙 후보 + 근거(evidence) + 못 찾은 항목. 5개 주제 |
| `data/interactions_seed.csv` | 병용 규칙 (성분A × 성분B × 종) |
| `data/rules_seed.csv` | 독성 규칙 (물질 × 종) |
| `data/rule_sources_seed.csv` | 규칙별 출처 (URL, 등급, 확인일, 근거 요약) |
| `scripts/build_seed.py` | 후보 JSON → 검증 → CSV. 재실행 가능 |
| `scripts/export_review_xlsx.py` | 수의사 검토용 xlsx 생성 (`out/`, git 제외) |

`build_seed.py`가 자동으로 거르는 것
- 허용 목록 밖 출처, 출처·근거 누락, 종 코드 오류
- **용량 숫자**(mg, mg/kg 등)가 들어간 문장, **집에서 구토를 유도하라는 지시**
- 3등급 출처만으로 매긴 "함께 쓰면 안 됨" → "주의"로 자동 하향
- 출처끼리 등급이 다르면 더 위험한 쪽으로 두고 `source_conflict=Y` 표시 (병용 7건)

## 4. 알려진 한계 (수의사 검토 때 같이 전달할 것)
1. **특수동물 병용 규칙 0건.** 토끼·햄스터·앵무새·고슴도치는 무료 자료에서 병용 정보를 찾지 못했다. 이 종들은 병용을 조회하면 모두 "확인된 정보 없음"으로 나온다. 채우려면 Carpenter's Exotic Animal Formulary가 필요하다.
2. **일부 병용 규칙은 종을 문서 범위로 판단했다.** Plumb's 블로그와 트라마돌 리뷰(PMC8520146)는 문장마다 종을 밝히지 않고 "개·고양이"를 다룬다고만 한다.
3. **병용 규칙 상당수가 약물군 단위다**(예: "NSAID계 + 스테로이드"). 이부프로펜·나프록센은 개별 병용 문장을 찾지 못했고, NSAID 약물군 규칙으로만 다룬다. → Phase 3에 **약물군 소속 테이블**이 필요하다(아래 5-1).
4. 일부 출처 페이지는 봇 차단으로 열지 못했다: ANSES, WSU MDR1, AAHA, BluePearl, VIN. 대신 다른 허용 출처를 썼다.
5. 등급 판단이 갈리는 항목: 칼랑코에(위험 vs 주의), 개의 아스피린, 고양이 에센셜오일 10종(개별 심각도 정보 없음), 조류의 알코올·스프레이. 엑셀에서 검토받을 것.
6. 대처 문장은 원문에서 가져오지 않고 일반 문구로 썼다("즉시 동물병원·중독상담 연락, 집에서 구토 유도 금지" 등).

## 5. 다음 단계에서 결정할 것
1. **ERD 추가 — `substance_class_member`(약물군 → 성분).** 예: NSAID계 → 이부프로펜, 나프록센, 아스피린, 멜록시캄, 카프로펜… 이게 있어야 "판콜에이(아세트아미노펜…) + 카프로펜"을 조회했을 때 약물군 규칙이 걸린다. 소속 정보도 출처가 필요하다. 약리 분류는 Merck에서 확인할 수 있다.
2. **고양이 자일리톨**: Merck는 저혈당·간손상 위험이 없다고 하지만 "비독성"이라는 표현은 없다. 🟢으로 둘지, 규칙 없이 둘지.
3. **개 백합 🟢**: ASPCA 근거로 넣었다. 고양이에게는 치명적이라 화면에서 혼동될 수 있으니 유지할지.
4. 엑셀을 자문 수의사에게 보낼 시점. 지금 보낼지, Phase 3 이후에 보낼지.

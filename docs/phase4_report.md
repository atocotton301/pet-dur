# Phase 4 보고 — 프론트 MVP (2026-11-25)

## 1. 기술 선택 변경: Next.js → FastAPI가 서빙하는 정적 화면 (HTML·CSS·바닐라 JS)
- 이유: 빌드 단계와 Node 서버가 없어서 **배포가 서비스 1개로 끝난다**(Render 무료 티어 하나면 됨). 화면이 4개뿐이라 프레임워크가 필요 없다.
- 나중에 Next.js로 옮겨도 API(`/api/*`)는 그대로 쓴다.
- API 경로를 `/api` 아래로 옮겼다(`/api/search` 등). 테스트도 함께 고쳤고 25개 모두 통과.

## 2. 화면 흐름 (`app/static/`)
1. **종 선택**: 6종을 이모지 버튼으로. 마지막에 고른 종은 브라우저에 기억한다.
2. **검색**: 제품명·성분·음식·식물. 예시 칩(타이레놀, 포도, 아보카도, 백합, 트라마돌).
3. **결과 카드**: 맨 위 색 띠로 등급을 바로 보여준다(🔴 위험 / 🟠 주의 / 🟢 일반적으로 독성 보고 없음 / ⚪ 확인된 정보 없음). 이어서 이유, 증상, 대처, "수의사 감수 전" 표시, 출처 펼치기.
   - 사람 약 제품: 성분별 등급 목록 + 종합 등급 + 위험 성분의 이유
   - 동물약 제품명: "동물용 의약품입니다. 처방·라벨대로, 다른 종에게 쓰지 마세요"
   - 검색 결과가 없을 때: "찾을 수 없다는 것이 안전하다는 뜻은 아닙니다"
4. **같이 먹여도 될까? (병용 점검)**: 카드마다 `+ 같이 먹여도 되는지 확인` 버튼이 있고, 누르면 화면 아래 트레이에 담긴다. 2개 이상 담으면 확인할 수 있다. 결과는 종합 등급 → 쌍별 등급 → 걸린 규칙(어떤 성분 때문에, 약물군 규칙이면 그 표시) → 기전·안내·출처 순서로 보여준다. 같은 성분이 겹치면 경고하고, 확인되지 않은 성분은 목록으로 보여준다.
5. **응급 병원**: 위험(🔴) 결과나 "함께 쓰면 안 됨" 결과가 나오면 "이미 먹었다면 바로 연락" 안내와 `📍 가까운 동물병원 찾기` 버튼이 뜬다. 위치를 허용하면 반경 10km 안 병원을 가까운 순으로, 전화 버튼과 함께 보여준다. 이름에 24가 있으면 **"24시(추정)"** 배지를 달고, 방문 전에 전화로 확인하라는 안내를 붙인다.
6. 모든 화면 하단에 "이 정보는 수의사 진료를 대체하지 않습니다"와 사용 공공데이터를 표시한다.

## 3. 확인한 것 (브라우저 375px 모바일 화면)
- 고양이 + "타이레놀콜드" → 🔴 위험, 성분 4개 각각 판정(아세트아미노펜·슈도에페드린 위험, 나머지 정보 없음)
- 트레이에 [타이레놀콜드-에스정, 트라마돌] → 🟠 주의 (아세트아미노펜 + 트라마돌 규칙)
- 고양이 + "백합" → 🔴 → 병원 찾기 → 성북·종로 병원 8곳, "24 애니동물병원"에 24시(추정) 배지. 위치는 테스트용 좌표로 대신했다.
- 가로 스크롤 없음, 콘솔 오류 없음
- 다크 모드 색은 만들어 두었지만 직접 확인하지는 않았다.

## 4. 실행
```
python scripts/load_db.py
python -m uvicorn app.main:app --port 8000    # http://localhost:8000
```

## 출처 등급 원칙 (rule_source에 기록)

1. **1차**: 동료심사 논문, 수의학 교과서/포뮬러리, 정부기관(FDA·ANSES·검역본부)
2. **2차**: 대학 수의대·전문학회(AAHA·WSAVA), Merck Vet Manual, ASPCA·Pet Poison Helpline
3. **보조**: 임상 해설지(dvm360·Clinician's Brief), 국내 수의 언론

병용 규칙의 🔴(함께 쓰면 안 됨) 등급은 **1·2차 출처가 있을 때만** 매긴다. 보조 출처만 있으면 🟠 주의까지만 매기고, 감수 상태는 "미감수"로 둔다.
